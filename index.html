About Me

I'm a web developer based in Gujranwala, Pakistan, currently completing an ADP in Information Technology at IISAT University (2023–2025). My work centers on the PHP + MySQL stack — I've built role-based systems with proper CRUD operations, admin dashboards, and AJAX-driven interfaces that don't need a page reload to feel responsive.

What I enjoy most is the logic underneath the interface: designing a database schema that makes sense, writing queries that scale past a demo, and structuring an admin panel so a non-technical user can actually manage it. I pair that with a front end built carefully in HTML and CSS — no shortcuts, no unnecessary bloat.

Outside of coursework projects, I spend my time solving problems for fun, reading through documentation, and staying in shape — I think clear code and a clear head come from the same discipline.
